M/S Shivlakhan Kesharwani Bartan Bhandar — Android app source project

Features:
- Per-kg rate input saved on the phone.
- Weight input in grams.
- Instant price calculation: rate × grams ÷ 1000.
- Clear (✕) button next to the weight field. It clears only weight.
- Offline use; no internet permission is required.

APK banane ke liye:
1. Computer par Android Studio install karein.
2. Android Studio mein "Open" karke is ZIP ko extract karne ke baad
   ShivlakhanBartanAndroid folder select karein.
3. Gradle sync complete hone dein.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) par click karein.
5. Android Studio APK ka location dikhayega. APK ko mobile mein bhej kar install karein.
   Pehli baar install karte waqt Android unknown-source permission pooch sakta hai.

Note: Yeh Android Studio project source hai, pre-built APK nahi.
